# Fonts

Self-hosted so that visitors never contact Google Fonts.

- **Nunito** — latin subset, variable `woff2` (weights 400–800), downloaded from Google Fonts.
- Licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/) (© The Nunito Project Authors).
- `fonts.css` is derived from the CSS Google Fonts serves; to refresh the file, fetch
  `https://fonts.googleapis.com/css2?family=Nunito:wght@400..800&display=swap`
  with a modern browser user-agent and keep the `latin` block.
