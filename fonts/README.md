# Fonts

Self-hosted so that visitors never contact Google Fonts.

- **Inter** and **Playfair Display** — latin subset, variable `woff2`, downloaded from Google Fonts.
- Both are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/) (Inter © The Inter Project Authors; Playfair Display © The Playfair Display Project Authors).
- `fonts.css` is derived from the CSS Google Fonts serves; to refresh the files, fetch
  `https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,600;0,700;0,900;1,600;1,700&family=Inter:wght@400;500;600;700&display=swap`
  with a modern browser user-agent and keep the `latin` blocks.
